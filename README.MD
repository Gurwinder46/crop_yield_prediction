# Crop Yield Prediction Using Machine Learning

## Project Overview

This project uses Machine Learning to predict crop yield based on agricultural and environmental parameters.

## Machine Learning Algorithm

Random Forest Regressor

## Input Parameters

- Rainfall
- Temperature
- Humidity
- Fertilizer
- Pesticide
- Crop Type

## Technologies Used

Python, Pandas, NumPy, Matplotlib, Scikit-learn, Joblib, Streamlit and Jupyter Notebook.

## Application

A Streamlit web application is developed to provide an interactive interface for crop yield prediction.

## Model Performance

R² Score: 94.68%
